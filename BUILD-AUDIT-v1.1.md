# Young Minds Bible v1.1 Build Audit

- New PastorAbayomi Bible Stories logo embedded at `assets/images/pastor_abayomi_logo.png`.
- Logo added to onboarding and home header.
- Launcher icon generation configured with `flutter_launcher_icons`.
- `codemagic.yaml` added for a fresh Android build.
- Codemagic regenerates missing Android scaffolding, installs packages, generates launcher icons, downloads the full KJV corpus at build time, verifies all 66 books, runs `flutter analyze`, then builds both release APK and AAB.
- App version advanced to `1.1.0+2` so the new build has a higher Android build number.

## Important audit finding
The recovered ZIP's local `assets/data/kjv.json` is only a placeholder and contains zero books. The Codemagic workflow is therefore configured to fetch and verify the complete Bible **before** compiling. If that fetch or verification fails, the build stops rather than publishing an incomplete offline Bible.

## Release signing
The workflow currently builds a release artifact using the Android project generated by Flutter. For Google Play production updates, configure your Android keystore/signing credentials in Codemagic before publishing a signed production AAB.
