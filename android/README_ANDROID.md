# Android project

This directory is the native Android host for the Flutter app.

Important: GitHub may still display **Dart** as the repository's primary language. That is normal for Flutter apps because Flutter UI/business logic is written in Dart. The Android host is here under `android/` and includes Gradle/Kotlin build configuration.

The Gradle wrapper JAR is intentionally regenerated by Flutter in CI (`flutter create . --platforms=android ...`) before building. This keeps the repository portable in environments where the Flutter SDK generates the wrapper.
