# Why GitHub says Dart

Young Minds Bible is a Flutter application. Flutter app source is primarily written in Dart, so GitHub Linguist normally reports **Dart** as the repository language. GitHub does not use a separate “Flutter” programming-language label.

The Android host project is under `android/`. The release workflow is `.github/workflows/build-android.yml`.

A valid repository root should contain `pubspec.yaml`, `lib/`, `android/`, `.github/`, `assets/`, and `test/`.
